Name statements by their dates

Reads the period off each page and renames the file, so a folder of statements falls into order
Bank statements arrive named things like statement_4471.pdf, which tells you nothing and sorts into no useful order. This reads the dates on each one and gives it a name that starts with its period — 2026-08-16 to 2026-09-15 — statement.pdf — so the folder sorts itself into date order. Nothing else about the file is touched: what comes out is the same document, under a better name. Your files never leave this computer. The reading is done here in the browser; nothing is uploaded and nothing is stored.
1 · The files
One page each is enough — if a statement is several sheets in one PDF, only the first is read. Split it first if you want a name per sheet.
