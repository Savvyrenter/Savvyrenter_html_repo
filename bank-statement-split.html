Split a PDF into single pages

One file per page, named in order — the first step before anything else
A statement usually arrives as one PDF of several sheets. Everything else — redacting, naming, putting a bundle together — is easier one page at a time. This splits it, and nothing else: each page comes out as its own PDF, exactly as it was, with its number in the name. The file never leaves this computer. Nothing is uploaded and nothing is stored.
